# 桌面管理 UI 规范

## 1. 设计目标

UI 应像一个专用的小型系统工具，而不是把 Codex++ 的全部功能重新复制一遍。用户打开窗口后，应在几秒内回答三个问题：

1. Codex 是否由加载器正常管理？
2. 哪些脚本正在运行，是否有错误？
3. 如何加载、停用或重新加载一个脚本？

默认语言为简体中文，支持英文。主题跟随系统，也允许手动选择深色或浅色。颜色必须使用语义 token，避免深色背景出现黑字。

## 2. 信息架构

```text
Codex Script Loader
├─ 总览
│  ├─ Codex/CDP 状态
│  ├─ 脚本运行摘要
│  ├─ 最近活动
│  └─ 快捷操作
├─ 脚本
│  ├─ 已安装列表
│  ├─ 加载本地脚本
│  ├─ 脚本详情/权限/日志
│  └─ Codex++ 迁移
├─ 诊断
│  ├─ Doctor 检查
│  ├─ 实时日志
│  └─ 导出诊断包
└─ 设置
   ├─ 启动与托盘
   ├─ 主题与语言
   ├─ 更新策略
   └─ 数据目录
```

## 3. 应用框架

- 左侧窄导航：总览、脚本、诊断、设置。
- 顶部状态条：Codex 状态、CDP 状态、安全模式和主操作。
- 主内容区域最大宽度适中，避免超宽屏信息分散。
- 右侧详情使用 modal/drawer，不让用户离开当前脚本列表。
- 关键状态同时使用颜色、图标和文字，不只依赖颜色。

## 4. 总览页

### 状态卡

- Codex：未运行 / 正在启动 / 正常 / 需要重启 / 异常；
- CDP：未连接 / 连接中 / 已连接 / 重连中 / 被拒绝；
- 脚本：启用数量、错误数量、最近注入时间；
- 安全模式：正常 / 已启用 / 因崩溃自动启用。

### 主操作

- `启动 Codex`：Codex 未运行时；
- `显示 Codex`：受管实例已运行时；
- `受控重启`：已有非受管实例或需要应用启动参数时；
- `重新加载全部`：只对已连接 renderer 可用；
- `安全模式启动`：显式二级操作。

### 最近活动

只显示最近 20 条摘要，通过增量事件更新。完整日志在诊断页，避免总览因大量日志重排而卡顿。

## 5. 脚本页

### 列表字段

- 名称、版本和脚本 ID；
- 来源：本地文件 / 本地目录 / Codex++ 迁移 / GitHub Release；
- 状态：已运行 / 已停用 / 正在加载 / 错误 / 需要重启；
- 最后注入时间；
- 开关、重新加载和更多菜单。

支持按状态过滤和名称搜索。脚本较多时列表使用虚拟化，不在滚动事件中同步扫描 DOM。

### 加载脚本向导

入口支持：

- 选择单个 `.js`；
- 选择包含 `manifest.json` 的目录；
- 拖放受支持的本地包；
- 从 Codex++ 目录导入；
- 后续版本从 GitHub Release 安装。

向导分三步：

1. 选择来源；
2. 检查 manifest、入口、哈希、权限和冲突；
3. 确认复制到 loader 数据目录并选择是否立即启用。

任何脚本都不得仅因被选择就立即执行。

### 脚本详情

- 基本信息、来源路径、SHA-256；
- 权限声明；
- 当前 document/target 注入状态；
- 最近错误和启动耗时；
- `重新加载`、`停用`、`打开目录`、`回滚`、`移除`。

移除脚本默认移到加载器回收区，不永久删除源文件。

## 6. 诊断页

- `运行完整检查`；
- 逐项展示 Codex 安装、宿主进程、CDP loopback、target、脚本完整性和 bridge 兼容；
- 实时日志支持级别和脚本过滤；
- 日志批量追加并节流渲染，默认最多保留可见 1,000 条；
- `导出诊断包` 必须在导出前列出内容，并对路径、URL 和凭据脱敏；
- 禁止把会话正文或认证文件加入诊断包。

## 7. 设置页

- 随系统启动加载器；
- 启动加载器时是否自动启动 Codex；
- 关闭窗口：隐藏到托盘 / 退出 UI / 退出全部；
- Codex 已运行但未受管时：询问 / 提示重启 / 不处理；
- 主题：跟随系统 / 浅色 / 深色；
- 语言：中文 / English；
- 更新：手动 / 仅检查 / 自动安装（后续）；
- 脚本更新独立设置，默认仅检查；
- 显示数据目录、脚本目录和日志目录。

## 8. 错误与危险操作

- CDP 启动失败：保留原生 Codex 可用，显示诊断入口，不循环拉起进程；
- 脚本异常：隔离该脚本，其他脚本继续运行；
- renderer 崩溃：下次进入安全模式并说明触发原因；
- 重启 Codex：先提示保存未发送输入；
- 移除/回滚：显示精确目标，不使用模糊批量删除；
- 非 loopback CDP：直接拒绝并显示安全说明。

## 9. 可访问性与性能

- 全键盘操作，焦点环清晰；
- 正文和控件满足 WCAG AA 对比度；
- `prefers-reduced-motion` 下关闭非必要动画；
- 页面切换不重新初始化 supervisor；
- 日志和状态事件批量处理，避免每条事件触发全树渲染；
- 脚本开关操作使用乐观状态，但后端失败时必须回滚并显示原因；
- 不在 UI renderer 中运行被管理的 Codex 脚本。
