# Bennett UI Improvements package

This package is adapted from Bennett's `b-nnett/codex-plusplus-bennett-ui`
project and retains its MIT license and copyright notice.

Version 1.4.10 is the current renderer-only compatibility baseline for Codex
Desktop. It retains the Bennett settings panel, usage control, project and
conversation colour styling, focused formula/local-image preview enhancement, slash-menu polish,
stable native thread-menu actions, compacted-context title regeneration, and native thread export and permanent deletion while leaving conversation
pagination to Codex.

BigPizzaV3 Codex++ support ended with the market-published version 1.2.4.
Versions after 1.2.4, including this bundled 1.4.10 package, target Codex Script
Loader and are not published, tested, or supported for Codex++.
