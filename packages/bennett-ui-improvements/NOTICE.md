# Bennett UI Improvements package

This package is adapted from Bennett's `b-nnett/codex-plusplus-bennett-ui`
project and retains its MIT license and copyright notice.

Version 1.4.3 is the current renderer-only compatibility baseline for Codex
Desktop. It retains the Bennett settings panel, usage control, project and
conversation colour styling, Markdown preview enhancement, slash-menu polish,
and native thread export and permanent deletion while leaving conversation
pagination to Codex.
